# Project Chromatic Odyssey — Build Roadmap

The game is built in **jobs**. Each job is one focused work session that ends in
something runnable. Later jobs build on earlier ones. Every job is checked
against the 5 pillars in [GDD.md](GDD.md).

**Stack:** TypeScript + Three.js (WebGL2), bundled with Vite. It runs in any modern
browser. Terrain, vegetation and core structures are procedural; selected hero
pieces use optimized GLB assets generated by the Blender pipeline.

**Camera:** the game became **first-person** after Job 4 (a kinetic movement pass added
wall-running, air slams and slam rebounds; see `npm run kinetictest`). Job notes below
that mention a chase camera or third person describe the state at the time.

## Job 2 — Player Movement ✅

- [x] "The Wayfarer's Trial" course: slide ramp, low tunnel, wall-jump shaft,

- [x] `npm run movetest`: 11 headless movement assertions

**Why not Rapier:** arcade movement wants exact control over slides and wall-jumps
rather than a generic solver; the terrain is an analytic height function, so ground
contact is exact and free with no trimesh baking (which matters once Job 6 streams
chunks); and it keeps the project dependency-free. Props are simple shapes, so
primitives are enough.

**Tuning:** all constants live in `PLAYER_TUNING` at the top of
`src/player/PlayerController.ts`. Change a number, run `npm run movetest`.

**Two real bugs this job caught**
- Restoring the controller's contact list with `.length = n` could *grow* the array with
  holes, so the next step read `undefined.normal` and the game loop died. It now restores by copy.
- Edge-triggered input was cleared every frame, but hit-stop nearly freezes the fixed
  clock — so combo clicks pressed during hit-stop were swallowed. `Input.endFrame` now
  only consumes edges when a fixed step actually ran.
