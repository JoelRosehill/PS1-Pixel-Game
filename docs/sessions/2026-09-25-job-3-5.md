# Job 3.5 — Blender asset pipeline and hero models

The user authorized converting every supplied asset to a faster, low-poly common
format and completing Job 3.5. Read alongside the earlier
[takeover note](2026-09-25-takeover.md) and archived session transcript.

## Delivered

- Converted all 40 archives to 40 self-contained GLB models with embedded PNGs.
  Original ZIPs are unchanged. Nested RAR/ZIP sources and Cyrillic paths are handled.
- Used Blender 5.2.1 LTS in background mode, disabling automatic source script execution.
- Reduced total geometry from 1,654,255 to 192,611 triangles (88.4% reduction).
  Runtime library totals 20.02 MiB; textures are at most 256 pixels per side.
- Preserved named modular parts, rigs and supplied animation clips. Consolidated
  large static scenes, repaired texture references and simplified materials.
- Added a resumable build pipeline, source hashes, manifest, conversion reports,
  credit inventory and a development model viewer.
- Added a cached runtime loader with skeleton cloning and pixel/toon materials.
- Integrated the broadsword with the existing player's anchors, plus chapel,
  eight graveyard pieces, shadow demon and an animated dragon in the proving grounds.
  Only these five packs download at startup. Combat hitboxes remain analytic.

## Boundaries and next work

The dragon and demon are model demonstrations, not implemented enemies/bosses.
The chapel has a conservative exterior collider. Original course and combat remain.
Castle XIII and The Lost Relic retain approximately 51K and 43K triangles because
further decimation removes disconnected detail. Neither environment loads in-game.
The Lost Relic source lacks textures/vertex colours; the horse retains its supplied
unusual pose and test animation clips. Source poses are not finished gameplay animation.
No source licences were supplied; the inventory records this without inventing credits.
