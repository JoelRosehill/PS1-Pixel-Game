# Job 10 — Audio, UI & Polish

## Delivered

- **Procedural chill-fi score** (`src/audio/Music.ts`): 16th-note lookahead scheduler;
  FM electric piano, bass, swung drums, kalimba melody, pads. Nine chapter moods plus the
  dawn; intensities title / explore / combat / boss / rest / finale, switched on bar lines.
- **AudioEngine**: music (tone filter + tape wobble), effects, ambience (vinyl crackle,
  speed-driven wind) → compressor; menus duck the score under a low-pass.
- **35 synthesised effects** (`Sfx.ts`, voices in `Synth.ts`) and a **SoundDirector**
  that reads game state (movement events, attack phases, counters, hits).
- **Menus** (`MenuUI`): title over a drifting camera (Continue / New journey with
  confirmation / Settings), pause on Esc or lost mouse capture, ending card with stats.
- **Settings** (`Settings`, own localStorage key): volumes, pixel size, depth bands
  (4/6/8), bloom, outlines, FOV, camera motion, compass, hints, debug overlay,
  sensitivity, invert Y, 15 rebindable actions (clashes swap; menus follow bindings).
- **Final HUD**: compass with region name and a marker toward the nearest unlit shrine,
  "Journey saved" indicator, key-aware hints, debug overlay off by default.
- **Pixel bloom** in the renderer: quarter-grid extract, separable blur, dithered screen
  blend at blit.
- **Performance**: band-count setting, change-only HUD DOM writes, `npm run perf`.
- **Production build**: relative base, three.js chunk, `npm run buildtest`.
- Tests: `npm run uitest` (19), `npm run buildtest` (8).

## Found and fixed

- Headless Chrome grants and then drops pointer lock, which opened the new pause menu in
  the middle of other suites. Screenshot/test runs (`shot=1`) no longer request pointer
  lock at all.
- Keys pressed in tests stayed "pressed" across many synchronous `step()` calls (edges
  are consumed by rendered frames), causing repeated jumps and queued attacks; the test
  harness now calls `input.endFrame()` after each press.
- The title camera first sat behind a plaza pillar and the gameplay HUD showed over the
  title; the camera moved and the HUD hides on the title screen.

## Measurements (no GPU available; SwiftShader)

`npm run perf` (script time per frame, render skipped): hub 0.6 ms, running out of the
hub 1.2 ms (p95 5 ms from streaming), Chapter II 0.5 ms, camp fight 3.8 ms average
including spawn frames, boss 1.5 ms. A CPU profile of a running fight shows script at
about 0.3 ms per frame. GPU cost scales with the number of depth bands (each band is a
scene pass); 4 bands are offered for slower machines.
