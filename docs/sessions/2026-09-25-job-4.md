# Job 4 — The Living Spellbook

User request: complete Job 4. All roadmap requirements implemented.

## Delivered

- Physical hinged book carried on the player's hip, floating open when casting.
  Page count increases thickness; binding upgrades at 3, 5 and 8 pages.
- Typed page catalog, session inventory, eight spell effects, seven world pickups.
  The original trial reward now unlocks Windstep. F binds nearby pages once.
- E casts; B reads/flips/equips; hold Tab opens the eight-slot quick-wheel.
  Both menus pause the world, clear gameplay input and trap keyboard focus using
  a native dialog. Mouse, arrow keys and number keys work in the wheel.
- Spell HUD shows selection, Momentum cost, recovery, ward duration and feedback.
- Rune Burst, Ember Lance, Frost Needle, Violet Well, Windstep, Updraft, Ember Ward,
  Mend: all spend Momentum with Resonance discounts and per-spell recovery.
- Projectiles stop at geometry; Windstep sweeps the standing capsule; wells land
  on terrain or platform surfaces. Shared geometry/materials and bounded active
  spell counts keep runtime resources bounded.
- Readable desktop/narrow-screen book UI; missing-page clues, lore, page turning,
  focus indicators and reduced-motion support. The impeccable skill informed UI work;
  PRODUCT.md records the existing project brief and implementation defaults.

## Bugs caught during verification

- `ColliderWorld.sweepSphere` reused the same vector as penetration calculations,
  corrupting its march point when checking multiple nearby colliders. It now has
  its own vector. A wall test includes a preceding, non-intersecting collider.
- The training constructs' solid cylinders swallowed spells before damage queries
  reached the target. Bodies now carry a flag; spell geometry queries ignore bodies,
  then CombatWorld resolves hits. Character movement still collides with them.
- Violet Well could deliver a fifth pulse due to floating-point lifetime drift.
  Explicit pulse counts guarantee four hits.
- The new Rune Burst recovery timer required the old combat test to wait before
  testing a second cast's Resonance discount. Its original radial damage is retained.
