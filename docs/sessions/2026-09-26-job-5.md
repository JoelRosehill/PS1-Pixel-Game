# Job 5 — Enemy Ecology I

User request: inspect the repository, then build the rest of the game from the roadmap.
This session starts that sequence with Job 5.

## Delivered

- **Linux tooling first.** The browser tools only launched Chrome the Windows way.
  `tools/browser.mjs` now finds Playwright's Chromium, adds `--no-sandbox` on Linux and
  offers a `render=0` logic mode. With software WebGL at ~1 fps, the real-time suites had
  been failing for timing reasons; in logic mode they pass unchanged. A kinetictest race
  (asserting F6 before any frame ran) was fixed.
- **Enemy framework** in `src/enemies/`: director, base class, perception, attack
  tokens, telegraphs, projectiles, encounters.
- **Dynamic body colliders** in `ColliderWorld` (enemies and the sparring constructs).
- **Shadow Knight** and **Sunkeeper Wizard** with the rules recorded in the GDD.
- **Three encounters** in The Threshold, including the new Sunkeeper ruin.
- Target frame, blinding white-out, title cards, dithered death dissolve.
- `Game.step()` / `game.manual` for deterministic tests; `npm run enemytest`.

## Design calls made without asking

- The game had already become first-person (undocumented). Enemies, tells and the HUD
  target frame are designed for first person; docs now say so.
- Spells pierce the knight's shield (still draining poise), so Momentum is the answer to
  a turtling knight and Frost Needle still interrupts as its page promises.
- Violet Well's pull was strengthened (−4 → −10 knockback per pulse): against armoured
  knights the old value barely moved them.
- Killing enemies pays Momentum; clearing an encounter heals and pays Momentum.
